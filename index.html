Marcar lecturas

Para marcar qué libros habéis leído, conecta este dispositivo una sola vez. Las marcas se guardan en GitHub y las veis los dos.

  1. Crea un token en GitHub (ya viene rellenado).
  2. En Repository access elige Only select repositories → biblioteca-lecturas y comprueba que Contents está en Read and write.
  3. Pulsa Generate token, cópialo y pégalo aquí:

El token solo puede modificar la lista de lecturas, nunca la web, y se queda guardado en este dispositivo.
